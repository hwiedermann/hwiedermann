## Hi, I'm Hendrik 👋

🏠 Tinkering with my **smart home** &nbsp;·&nbsp; 🖨️ and with **3D printing**

Hobbyist from Germany 🇩🇪. My smart home runs on **ioBroker** on a small NUC, and I print on an **Anycubic Kobra S1**. When a building block is missing, I build an **ioBroker adapter** out of personal interest – or contribute small fixes to existing ones.

💬 Ask me about **ioBroker**, **smart home** and **3D printing**.
